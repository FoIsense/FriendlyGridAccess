# Friendly Grid Access v0.5.0

Two-part Space Engineers PC project:

1. **TorchPlugin** — server authority, persistence, faction/reputation validation and access patches.
2. **WorkshopMod** — client terminal UI with a friendly-faction selector and Grant/Revoke buttons.

## What v0.5.0 carries forward
- Default minimum reputation is **500**.
- Ownership stays with the original player/faction.
- Explicit per-grid grants; reputation alone does not auto-share a grid.
- Whole-grid grants persist across restarts.
- Grid lookup uses distance to the grid world bounding box, not grid center.
- Current SE/Torch-compatible Harmony argument binding uses positional `__0` where possible.
- Patch targets are non-fatal: if Keen changes one path, Torch can still boot and logs which target failed.
- Optional `DebugAccessChecks` logging for diagnosing owned doors/cockpits/cargo paths.
- Existing `!fga` commands remain as fallback/admin UI.
- Workshop UI sends requests to the Torch plugin over a secure mod message channel; the server independently verifies player, grid ownership/faction leadership, target faction and reputation.

## Important limitation
v0.4.x proved that grant/reputation/storage and the standard terminal access hooks work, but some **owned block interactions may still use additional game-specific use/ownership checks**. v0.5.0 keeps the known hooks and adds diagnostics rather than pretending this is fully solved. If an owned door/cockpit/cargo block still denies an approved friendly player, set `DebugAccessChecks` to `true`, reproduce once, and inspect Torch logs before adding another patch.

## Build Torch plugin
Use `.github/workflows/build-release.yml` on GitHub Actions. A tagged release (`v0.5.0`) produces `FriendlyGridAccess-0.5.0.zip`.

## Install Torch plugin
Place the generated ZIP in the server `Plugins` directory and add this GUID to `Torch.cfg`:

`26f55d62-7b65-4e78-a347-dabf640d66d1`

## Install Workshop companion mod
Publish the contents of `WorkshopMod/` as a normal Space Engineers Workshop mod, then add that Workshop item to the server world's Mods list. Clients joining the server will receive the mod normally.

## Commands
- `!fga status`
- `!fga list`
- `!fga grant TAG`
- `!fga revoke TAG`

## Config
Generated by the Torch plugin:
```json
{
  "MinimumReputation": 500,
  "CommandGridSearchRadiusMeters": 25.0,
  "RequireFactionLeaderOrFounder": true,
  "DebugAccessChecks": false
}
```
