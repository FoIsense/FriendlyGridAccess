# Contributing

Thanks for helping improve Friendly Grid Access.

## Development rules

1. Keep ownership with the original faction unless a feature explicitly says otherwise.
2. Keep access decisions server-authoritative.
3. Never turn vanilla `true` access into `false` in the Friendly Grid Access patch.
4. Re-check faction reputation when evaluating an extra-access grant.
5. Treat internal Space Engineers method signatures as version-sensitive and fail clearly when a required patch target cannot be found.

## Testing

Before opening a pull request, test on a non-production dedicated server and include the Space Engineers and Torch versions used.
